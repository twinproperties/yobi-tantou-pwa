予備試験 短答 肢トレ v005（令和8・7・6年度 全7科目）

■ ファイル構成（リポジトリ直下にそのままアップ）
- index.html / sw.js / app-sw.js / manifest.webmanifest / .nojekyll
- icons/ （icon-180.png, icon-192.png, icon-512.png）
- data/ （R08.js = 令和8年度, R07.js = 令和7年度, R06.js = 令和6年度）

■ 年度を増やすとき
data フォルダに R06.js, R05.js … のように「R+年度2桁.js」（平成は H30.js 形式）を追加アップするだけ。
アプリが自動で読み込み、年度の選択肢に出ます（index.html の変更は不要）。
反映されない時は app-sw.js の VERSION の数字を1つ上げてアップ。

■ 古い questions.js について
v003で使っていた questions.js はもう使いません。リポジトリに残っていても無害ですが、削除して構いません。

■ 公開手順（初回のみ）
1. GitHubにファイルをアップ（icons と data はフォルダごと）
2. Settings → Pages → Branch を main / (root) にして Save
3. 出たURLをスマホChromeで開く → ⋮ → 「ホーム画面に追加」

■ 注意
- 正誤は公式解答（法務省の正解）・予備校解答から肢別に展開したデータです。
- 個数を問う問題は各肢の○×を法的検討で特定しています（個数と一致を確認済み）。status 欄に「個数条件＋法的検討から特定」と記載。
- 空欄補充（語句群）の問題は、選択肢ごとに「組合せ全体が正しいか」を○×にしています（正解肢のみ○）。
- 現行法との照合は未実施（出題当時の正誤）。
- 無料のGitHub Pagesは公開リポジトリが前提です。

■ 記録
- ○×を押すと正誤が記録され、「間違えた肢のみ」で復習できます（端末内 localStorage）。
